# Changelog

Notable user-facing changes are documented here. The project follows [Semantic Versioning](https://semver.org/).

## Unreleased

## 21.0.3 — 2026-08-12

### Added

- Accessible loading, empty, error, and retry states.
- Unique combobox, listbox, and active-option relationships.
- Keyboard opening, Escape focus restoration, Home, End, Page Up, and Page Down navigation.
- Contextual labels for search and panel-close controls.
- Crawlable clean documentation URLs with prerendered route content.
- Product-focused landing page and accessibility guide.

### Changed

- Client-side default matching is trimmed and case-insensitive.
- Clear and close interactions use native buttons.
- Documentation, contribution, security, and publishing guidance has been refreshed.

## 21.0.2 — 2026-08-07

- Added Angular 21 and 22 consumer verification.
- Improved package metadata and documentation search content.

For older releases, see [GitHub tags](https://github.com/alireza-sohrabi/ngx-mat-select/tags) and the npm version history.
