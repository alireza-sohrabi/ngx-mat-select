

Each `ngx-mat-select` major version targets the matching Angular and Angular Material major version.

| Angular | Angular Material | ngx-mat-select |
|---------|------------------|----------------|
| 21.x or 22.x | 21.x or 22.x | 21.x        |
| 20.x    | 20.x             | 20.x           |
| 19.x    | 19.x             | 19.x           |
| 18.x    | 18.x             | 18.x           |
| 17.x    | 17.x             | 17.x           |
| 16.x    | 16.x             | 16.x           |
| 15.x    | 15.x             | 15.x           |
| 14.x    | 14.x             | 14.x           |

Install the package major that matches your Angular application:

```bash
npm install ngx-mat-select@21
```

Angular 21 and 22 consumers are verified from the package's public entry point in continuous integration.
